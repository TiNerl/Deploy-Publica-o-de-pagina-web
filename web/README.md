# RE:Vendas

## Resumo

Este repositório contém um protótipo simples de uma loja online chamada "RE:Vendas", desenvolvido em HTML e 
CSS. O código fornece uma estrutura básica para o site, incluindo um cabeçalho, seção heroica, grade de 
produtos e rodapé. A ideia principal é criar um exemplar para fazer praticar deploy no site "NetiFy". 

## Estrutura do Código

### Arquivos Principais

1. **index.html**: Este é o arquivo principal HTML que estrutura a página.
2. **styles.css**: Este arquivo CSS contém os estilos usados para formatar a página.
3. **images/examples.png**: Pasta destinada ás imagens contidas dentro do html 
### Implementações

#### index.html
- **Cabeçalho (`<header>`)**: Inclui o título "RE:Vendas" e uma barra de navegação com links para seções 
principais do site.
- **Seção Heroica (`#hero`)**: Exibe um banner com uma imagem de fundo, título e botão para iniciar as compras.
- **Grade de Produtos (`#products`)**: Mostra uma seleção de produtos com imagens, nomes e preços.
- **Rodapé (`<footer>`)**: Inclui uma simples declaração de direitos autorais.

#### styles.css
- Estilos globais para resetar margin e padding padrão.
- Estilos específicos para o corpo da página, incluindo fonte e linha de base.
- Estilos para o cabeçalho, barra de navegação, seção heroica, grade de produtos e rodapé.
- Efeitos interativos como transições de cores nos botões.

## Como Usar

1. **Clonar o Repositório**:
    ```bash
    git clone https://github.com/seu_usuario/re-vendas.git
    ```

2. **Navegar para o Diretório do Projeto**:
    ```bash
    cd re-vendas
    ```

3. **Abrir o Arquivo `index.html` em um Navegador Web**:
    - Você pode simplesmente clicar duas vezes no arquivo ou abrir-o usando qualquer navegador.
